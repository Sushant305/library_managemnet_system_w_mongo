# library_managemnet_system

## 🚀 Technologies Used

Node.js

Express.js

MongoDB

Mongoose

Nodemon

## 📦 Installation

Install all project dependencies:

npm install

## 🛠️ Manual Project Setup

If you are creating the project from scratch, run:

npm init
npm i express
npm i mongoose
npm i nodemon --save-dev

## ▶️ Run the Project

To start the application in development mode:

npm run dev

## 📚 Packages

Express

Used to create the backend server and APIs.

npm i express

Mongoose

Used to connect and interact with MongoDB.

npm i mongoose

Nodemon

Automatically restarts the server when changes are made.

npm i nodemon --save-dev

## 🔄 Restore Dependencies

If the node_modules folder or package-lock.json is deleted, restore the dependencies using:

npm install

 npm i dotenv
